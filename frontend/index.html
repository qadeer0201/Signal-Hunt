Morse Code
Dots, dashes and letter decoding

Morse code represents letters and numbers using short signals (dots ·) and long signals (dashes —). Each letter is separated by a small gap; words by a larger gap.


Key letters:

Binary ASCII
8-bit sequences and text conversion

ASCII maps characters to numbers. Binary represents those numbers in base-2. Each character = 8 bits (one byte).


Examples:

A = 65 = 01000001
B = 66 = 01000010
Z = 90 = 01011010
0 = 48 = 00110000
Space = 32 = 00100000


To decode: convert each 8-bit group to decimal, then look up the ASCII table.

FSK Signals
Frequency changes and waveform reference

FSK (Frequency-Shift Keying) encodes data by switching between two frequencies. A higher frequency represents a 1 (mark) and a lower frequency represents a 0 (space).


Remember:

High tone → 1 (mark)
Low tone → 0 (space)
Decode the sequence → convert binary → ASCII


Listen carefully to the frequency shifts at each station.
