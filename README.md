# Signal Hunt — Frontend Package

This package contains the participant frontend and a prototype Host Dashboard.

- Open `frontend/index.html` with Live Server for the participant UI.
- Open `frontend/host.html` on the same Live Server origin for the local host-start demo.
- For the local demo, the two pages must be open in the same browser profile; use the Start Challenge button in the host page.
- This does not start the game across different devices. That requires the FastAPI backend.

Read `frontend/README.md` for test codes and details, and `docs/BACKEND_INTEGRATION_NOTES.md` for integration responsibilities.
